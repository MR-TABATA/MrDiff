v0.4.0 ← v0.1.0 · 2026 年 9 月 13 – 12 日

CLI は無料で MIT。各リリースは universal binary（Apple silicon + Intel）の zip で、Homebrew の tap はそれを指す。

0.4.09/13 アーカイブ・Word 文書・フォント。zip なら何でも（docx・xlsx・pptx・EPUB・Sketch）目次からフォルダとして比べる。Word の本文は段落ごとの行 diff。フォント（OTF・TTF・TTC）は字形ごとに描いて画素で比べる。--json に archive・docx・font が増えた
0.3.09/13 フォルダ 2 つ。mrdiff old/ new/ で、どのファイルが違うか・片側にしか無いかを言う。--ssh がサーバ相手に返していた答えを、隣のフォルダに。--json に kind: "dir" が増えた
0.2.09/13 PDF。ページごとに描いて画像と同じ方法で比べ、どのページが違い、そのページのどこかを mm で言う。ページ数と紙の大きさの違いは別に言う。あわせて --help（スイッチごとに 1 行）と、1 回きりの言語切り替え --lang=en|ja
0.1.29/12 --version。配布物を作るスクリプトは、版がタグと合わない zip を作らない
0.1.19/12 画像の答えを 3 つ足す：画素ごとの印、違いの塊、全体の色の差（B − A のチャンネルごとの平均）。「44% が違う」と「全体が 20 明るく書き出された」を見分けられるように
0.1.09/12 最初のリリース。テキスト・画像・バイナリ・URL 2 つ・クリップボード・公開中のサイトと git 管理下のフォルダ（--site）・手元のディレクトリと SSH 越しのサーバ（--ssh）。--json と --exit-code は初日から。同日に Homebrew の tap を公開

この一覧について

  • 日付は GitHub の Release の日付（JST）。版は --version とタグのもの。
  • ここにある全リリースに配布物の zip がある。タグだけのものは無い。
  • JSON の形は v0.1.0 から固定。v0.2.0 で pdf、v0.3.0 で dir、v0.4.0 で archive・docx・font という kind が増えただけで、既存のものは変えていない。

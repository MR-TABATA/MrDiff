Release history

Four releases. One new kind of file.

From the first release on 12 September 2026 to v0.2.0 the next day. It shipped comparing text, images and binaries; a day later it compared PDFs and told you where on the page.

Newest first

v0.2.0 ← v0.1.0 · 13 – 12 Sep 2026

The CLI is free and MIT. Each release is a universal binary (Apple silicon + Intel) in a zip, and the Homebrew tap points at it.

0.2.013 Sep PDFs. Each page rendered and compared like an image; the answer says which pages differ and where on the page, in millimetres. Page counts and paper sizes are reported separately. Also --help with one line per option, and --lang=en|ja for a one-run language switch
0.1.212 Sep --version, and the release script refuses to build a zip whose version does not match the tag
0.1.112 Sep Three more answers for images: a per-pixel mask, the difference grouped into regions, and the overall tone shift (B − A per channel) — so "44% different" can be told apart from "exported 20 brighter"
0.1.012 Sep First release. Text, images, binaries, two URLs, the clipboard, a deployed site vs its git-tracked folder (--site), a local directory vs a server over SSH (--ssh). --json and --exit-code from day one. Homebrew tap published the same day

About this list

  • Dates are the GitHub release dates (JST). Version numbers follow --version and the tag.
  • Every release here is published with a downloadable zip; there are no tag-only entries.
  • The JSON shape is fixed from v0.1.0 on. v0.2.0 added the pdf kind; nothing existing changed.
